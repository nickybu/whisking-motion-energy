# Whisking Bout Analysis via Motion Energy

Detect and quantify whisking bouts from head-fixed mouse videos using frame-to-frame motion energy in user-defined ROIs. All analysis runs in a single Jupyter notebook (`whisking_analysis.ipynb`).

Note: current analysis only uses whisker ROI and ignores background ROI and arm ROI.
- motion energy calculation on raw whisker ROI seemed good enough
- arm ROI was included with the idea of automating stimulus presentation detection in the future

## Setup

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then:

```bash
uv run jupyter lab
```

This automatically creates a virtual environment, installs all dependencies, and launches JupyterLab.

## Notebook workflow

### 1. Configuration
Set the active video path and project directories. All subsequent cells reference these variables.

### 2. Interactive ROI selection
Draw rectangles on a video frame to define whisker, background, and arm ROIs. Coordinates are saved to `roi_config.json`, keyed by video filename. Background ROI enables background subtraction; arm ROI is optional.

### 3. Interactive video clipping
Mark segments to exclude (e.g. handling artifacts), keep everything else. Uses ffmpeg stream copy to extract trimmed video.

Note: requires `ffmpeg` on the system PATH.

### 4. ROI preview
Overlay ROI rectangles onto the trimmed video to verify placement.

### 5. Motion energy computation
Computes ME for each ROI as the mean squared pixel difference between consecutive grayscale frames:

$$ME(t) = \frac{1}{N_{px}} \sum_{ROI} (I(t) - I(t-1))^2$$

Units are mean squared intensity change per pixel (mean delta^2/px), making values comparable across ROIs and videos of different sizes. When a background ROI is provided, a background-subtracted signal is also computed.

Outputs per video:
- `{stem}_me.json` -- full results (video info, ROI config, ME timeseries)
- `{stem}_me_timeseries.csv` -- frame-by-frame ME values

### 6. Timeseries plots
Plots raw and Gaussian-smoothed ME over time. Use this to identify an appropriate bout detection threshold.

### 7. Heatmap and overlay videos
- **Heatmap video** (`{stem}_heatmap.mp4`) -- squared pixel differences visualised as a heatmap overlay within each ROI
- **Timeseries overlay video** (`{stem}_me_overlay.mp4`) -- heatmap overlay with a scrolling ME timeseries strip at the bottom.

### 8. Bout detection
Simple threshold-based detection with configurable parameters:

| Parameter | Default | Description |
|-----------|---------|-------------|
| `BOUT_THRESHOLD` | 50.0 | ME value above which frames are classified as whisking |
| `BOUT_MIN_DURATION` | 0.05 s | Discard bouts shorter than this |
| `BOUT_MERGE_GAP` | 0.05 s | Merge bouts separated by less than this |
| `BOUT_SIGMA` | 2.0 | Gaussian smoothing sigma before thresholding |

Pipeline: smooth signal, threshold, extract bouts from binary transitions, merge short gaps, remove short bouts.

Outputs per video:
- `{stem}_whisking_bouts_{signal_key}.csv` -- bout metadata (onset, offset, duration, mean/peak ME)
- `{stem}_whisking_binary_{signal_key}.csv` -- per-frame binary whisking signal

### 9. Bout detection overlay videos
- **Timeseries overlay video** (`{stem}_me_overlay.mp4`) -- re-run the `render_timeseries_video()` to generate a heatmap overlay with a scrolling ME timeseries strip at the bottom, which now visualises the whisking bout detection on the video.

### 10. Multi-video comparison
Generates 6 comparison plots across videos:

1. **Summary table** -- bout count, whisking %, duration stats, inter-bout-interval stats, peak ME
2. **Bout duration distribution** -- histogram
3. **Inter-bout interval distribution** -- histogram
4. **Bout raster** -- temporal layout of bouts per video
5. **Peak ME per bout** -- log10 histogram
6. **Cumulative whisking %** -- whisking percentage over session time
